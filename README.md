# بقالة العنزي — نظام الفواتير والمخزون ودفتر الحسابات المتكامل

نظام إدارة مبيعات وفواتير ومخزون وحسابات عملاء متكامل لبقالة العنزي / العزي للمواد الغذائية، يدعم واجهة عربية RTL كاملة مع تصميم متجاوب لجميع الأجهزة وطباعة حرارية 58mm/80mm ومشاركة واتساب مباشرة.

## المميزات والوظائف الرئيسية

- **لوحة التحكم والرئيسية (Dashboard)**:
  - إحصائيات فورية لمبيعات اليوم، إجمالي المبيعات، إجمالي ديون العملاء، وحالة المخزون.
  - تنبيهات فورية للأصناف التي قاربت على النفاد بالمخزون.
  - وصول سريع لجميع العمليات وقائمة بآخر الفواتير وأعلى العملاء مديونية.

- **فواتير المبيعات (Sales Invoices)**:
  - إنشاء فواتير سريعة مع الإكمال التلقائي لأسماء وأسعار الأصناف من المخزون.
  - دعم البيع النقدي والبيع الآجل (على الحساب).
  - حساب فوري للإجمالي، المبلغ المدفوع، والمتبقي، مع إظهار رصيد العميل قبل وبعد الفاتورة.
  - حفظ مسودات مؤقتة واستعادتها بضغطة زر.
  - خصم الكميات المباعة من المخزون تلقائياً عند حفظ الفاتورة.

- **دفتر الحسابات والعملاء (Customers & Ledger)**:
  - دليل العملاء مع البحث الفوري بالاسم أو رقم الهاتف.
  - كشف حساب تفصيلي لكل عميل يوضح جميع الحركات (فواتير، سدادات، قيود) مع الرصيد الجاري.
  - تسجيل سندات قبض وسداد دفعات نقدية أو قيد ديون جديدة.
  - إرسال كشف الحساب فوراً للعميل عبر تطبيق واتساب بنص منسق.

- **فواتير الشراء والتوريد (Purchases)**:
  - تسجيل فواتير الشراء من الموردين وتكلفة البضاعة.
  - تحديث وزيادة كميات الأصناف في المخزون تلقائياً.

- **إدارة المخزون والأصناف (Inventory)**:
  - تصنيف المنتجات (مواد أساسية، حبوب، زيوت وسمن، ألبان، معلبات، مشروبات...).
  - تحديد أسعار الشراء والبيع وحد التنبيه لنقص المخزون.
  - أزرار تعديل سريع للكميات (+1, +5, -1).

- **التقارير المالية والأرباح (Reports)**:
  - تقارير إجمالي المبيعات، إجمالي المشتريات، والأرباح التقديرية.
  - تقرير أعلى العملاء مديونية والأصناف الأكثر طلباً ومبيعاً.

- **الملاحظات والطلبيات (Notes)**:
  - تسجيل طلبات الموردين والملاحظات اليومية وتثبيت الهام منها في الأعلى.

- **الطباعة الحرارية والمشاركة**:
  - محاكي إيصال حراري احترافي 58mm/80mm مناسب للطابعات المحمولة وبلوتوث.
  - تصدير ومشاركة الفواتير وكشوفات الحسابات عبر واتساب.

- **النسخ الاحتياطي وإعدادات المتجر (Backup & Restore)**:
  - تصدير نسخة احتياطية كاملة بصيغة JSON.
  - استرجاع البيانات المحفوظة بسهولة.
  - تعديل اسم المحل ورقم الهاتف المطبوع على الإيصالات.
